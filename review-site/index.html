Mine Mail

本地优先桌面邮件客户端 · Local-first desktop email client

一封信，安静地抵达。 Mail, quietly where it belongs.

Mine Mail 是一款本地优先的桌面邮件客户端。邮件直接在你的设备与邮箱服务商之间同步，不经过 Mine Mail 自有服务器。 Mine Mail is a local-first desktop email client. Mail syncs directly between your device and your provider—never through a Mine Mail server.

Google OAuth 2.0

为什么需要 Gmail 完整邮箱权限？Why does Gmail require full mailbox access?

Mine Mail 是完整邮件客户端，通过 Google 支持的 IMAP 与 SMTP 协议读取、同步和发送邮件。Google 要求这两个协议使用同一个受限 scope。 Mine Mail is a full email client. It reads, synchronizes, and sends mail through Google-supported IMAP and SMTP. Google requires those protocols to use one restricted scope.

https://mail.google.com/

你在系统浏览器中登录 GoogleYou sign in to Google in your system browser

Mine Mail 使用授权码 + PKCE 和随机本地回调，不会看到你的 Google 密码。Mine Mail uses Authorization Code + PKCE with a random loopback callback and never sees your Google password.

Google 将授权 token 返回到本机Google returns authorization tokens locally

token 保存在操作系统凭据库，并仅用于 Gmail IMAP/SMTP 的 XOAUTH2 认证。Tokens are stored in the OS credential store and used only for Gmail IMAP/SMTP XOAUTH2 authentication.

设备直接连接 GmailYour device connects directly to Gmail

Mine Mail 开发者不接收邮件、token、联系人或附件。The Mine Mail developer does not receive mail, tokens, contacts, or attachments.

更窄 scope 无法维持当前协议架构Narrower scopes cannot support this protocol architecture

Gmail API 的只读或单项权限不能用于 IMAP/SMTP 登录，也无法覆盖同步草稿、状态和发信等完整客户端行为。Narrow Gmail API scopes cannot authenticate IMAP/SMTP or cover the complete client behavior required for drafts, state sync, and sending.

清晰的权限，随时可撤销。Clear access. Revocable at any time.
